# Getting help

Nisshi OSS is provided as-is, with community support only.

| You want to | Go to |
| --- | --- |
| Ask a question or discuss how to use Nisshi | The [Solace community](https://community.solace.com) |
| Report a bug or request a feature | [GitHub issues](https://github.com/nisshi-io/nisshi/issues) |
| Report a security vulnerability | [SECURITY.md](SECURITY.md). Don't use the forum or an issue. |
| Reach the maintainers when the community can't help | support@solace.com |

Before you ask, check the [README](README.md) and the
[documentation](https://docs.nisshi.io). If you are reporting a bug, include
the Nisshi version, the storage engine, and the steps to reproduce it.
